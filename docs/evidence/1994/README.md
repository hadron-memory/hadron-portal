Before the fix: two new More-item unit pins fail (13 controls pass); the extended browser fails on the long menu leaving the viewport. A base-class reorder turns the two existing selected-label pins red as well (4 failures total), exposing the fragile string replacement.

After the fix: 15 component pins and 76 browser cases pass. Six independent geometry mutants fail assertions: remove selected break-words, change the strict boundary to >=, remove menu-anywhere on the anchor/button separately, and restore nowrap on the anchor/button separately. Reordering the base classes after the fix is deliberately equivalent and all 15 tests pass. Each mutant was restored. Full/check/build results are recorded in the PR.

Menu wrap uses a SINGLE overflow-wrap:anywhere declaration. whitespace-normal + break-word wrapped text but left the shrink-to-fit menu 358px wide at x=-9 in a 390px viewport/308px column. Stacking anywhere with break-words left computed overflowWrap=break-word because of the utility cascade. One anywhere declaration fixes the intrinsic minimum as well as paint; menu placement, colours, roles, text and handlers are untouched. Selected labels retain the existing min-w-0/max-w-full/whitespace-normal/break-words/text-left swap. Every other base class, including coarse touch height and focus outline, is retained.
